# Privacy Policy

## Blocky - Element Blocker

Block Elements From Websites does not collect, sell, or share personal data.

## What the extension does

The extension allows the user to create rules to hide specific HTML elements on selected websites.

## Data storage

The extension stores only the following information:

- website domains entered by the user
- CSS selectors or HTML snippets entered by the user
- rule status such as active or inactive
- basic rule metadata such as creation order

This information is stored using Chrome storage to make the extension work correctly.

## What the extension does not do

The extension does not:

- collect personal identity information
- track browsing history for analytics
- send user data to external servers
- use ads
- use remote code
- require account login
